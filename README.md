# GeniusHub (alternate) integration for Home Assistant

The `geniushub_alt` integration builds upon the core [Genius Hub integration](https://www.home-assistant.io/integrations/geniushub/). It fixes some issues and adds some extra features such as Devices, and Reconfigure and Reload functionality.
